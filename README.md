# 💎 Jordan Pandji | Cinematic Personal Branding

Un portfolio de branding personnel ultra-premium conçu pour une présence visuelle forte et une élégance technologique.

## ✨ Vision du Projet
Ce site représente la convergence entre l'ingénierie IA, la philosophie de l'innovation et l'entrepreneuriat. Le design est inspiré des standards les plus élevés du luxe et des studios créatifs modernes.

## 🚀 Caractéristiques Techniques
- **Zéro JavaScript / Zéro Framework** : Une prouesse de design réalisée exclusivement en **HTML5** et **CSS3** pur.
- **Identité Visuelle "Obsidienne & Or Bruni"** : Palette sophistiquée utilisant des tons d'ambre royal et d'argent liquide sur fond noir profond.
- **Portrait Artistique Intégré** : Traitement visuel complexe du portrait (lueurs, masques, cadres asymétriques) via CSS.
- **Expérience Cinématographique** : Animations fluides, texture de grain et composition asymétrique moderne.
- **Totalement Responsive** : Adaptabilité complète sur mobile, tablette et desktop.

## 🛠️ Stack
- HTML5 Sémantique
- CSS3 Avancé (Variables, Grid, Flexbox, Keyframes, CSS Shapes)
- Google Fonts (Playfair Display & Inter)
